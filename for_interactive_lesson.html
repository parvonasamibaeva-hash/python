Что такое i? Это не специальная команда!

ПЕРЕМЕННАЯ

Буква i — обычное имя переменной. Часто её используют как короткое обозначение номера или индекса. Но Python не требует именно букву i: имя можно выбрать самостоятельно.

Можно использовать i, number, step, cat...
Имя переменной подставляется в код
for i in range(1, 5):
print(i)
i = 1→i = 2→i = 3→i = 4
Главное: имя переменной должно быть одинаковым в строке for и внутри команды print. Если написать for number, а потом print(i), Python не поймёт, откуда взять i.

Правила имени переменной (для начала):
• начинается с латинской буквы или знака _
• дальше могут быть буквы, цифры и _
• пробелы и дефисы использовать нельзя
• нельзя использовать зарезервированные слова Python, например for, if, while
• большие и маленькие буквы различаются: cat и Cat — разные имена.

Что пишется в скобках range()?

КОНСТРУКТОР ПОСЛЕДОВАТЕЛЬНОСТИ

Функция range() создаёт последовательность целых чисел. В круглых скобках указывают, откуда начинать, где остановиться и каким шагом двигаться.

Три возможных аргумента
range(start, stop, step)
start — начало
Первое число последовательности.
stop — граница остановки
Это число в последовательность НЕ входит.
step — шаг
На сколько увеличивать или уменьшать число.
Запятая ,
Разделяет аргументы. Скобки показывают, какие значения относятся к range().

ПОПРОБУЙ РАЗНЫЕ СКОБКИ

Выбери, сколько аргументов будет в скобках, затем измени числа.

Получившаяся команда
range(5)
Какие числа получатся?
01234
range(5) — Python начинает с 0 и идёт с шагом 1, пока не дойдёт до числа 5. Пятёрка не включается.

Четыре особенности скобок и range()

1. Одно число
range(5)
Начало автоматически равно 0, шаг — 1.
2. Два числа
range(2, 6)
Первое — начало, второе — граница остановки, шаг — 1.
3. Три числа
range(2, 10, 2)
Начало, граница и шаг задаются явно.
4. Шаг не может быть нулём
range(1, 5, 0) вызовет ошибку. Для движения назад используют отрицательный шаг.

В range() передают целые числа. Десятичные числа вроде 1.5 для range() не подходят.

Почему отступы так важны?

СТРУКТУРА PYTHON

В Python отступ — это не украшение и не просто красивое оформление. Именно по отступам Python понимает, какие команды входят внутрь цикла и должны повторяться.

Обрати внимание на четыре пробела перед print
for i in range(1, 4):
print(i)
Обычно используют 4 пробела. Все команды, которые относятся к одному блоку цикла, должны начинаться с одинакового отступа.

Запомни три правила

Команда с отступом
Входит в цикл и повторяется на каждой итерации.
Команда без отступа
Уже не входит в цикл. Она выполняется после того, как цикл закончится.
Нет отступа после for:
Python выдаст IndentationError — он ожидает блок команд с отступом.
Вложенный цикл или if
Для нового блока добавляют ещё один уровень отступа — обычно ещё 4 пробела.

🔵 for — перебираем

Подходит, когда есть последовательность элементов или заранее понятно, сколько раз нужно повторить действие.

for i in range(1, 4): print(i)

Как думает Python:
«Есть значения 1, 2, 3. Возьму первое, выполню команды. Потом второе. Потом третье. Значения закончились — стоп».

🟣 while — пока условие верно

Подходит, когда нужно повторять действие до тех пор, пока условие остаётся истинным.

while apples < 3: apples = apples + 1

Как думает Python:
«Проверю условие. Если True — выполню команды и проверю снова. Если False — остановлюсь».

Две похожие задачи — два способа

for: «Пройди по всем 5 станциям маршрута».
Количество станций известно заранее.
while: «Собирай яблоки, пока корзина не наполнится».
Продолжение зависит от условия.

Оба цикла иногда могут решить одну и ту же задачу. Но for особенно удобен для перебора последовательностей, а while — когда повторение зависит от условия.
